bloopers

制作组乐事

所有东西都在正常工作，只是不是按你想的那样工作。下面这些坑，都是写这游戏的时候真踩过的。

AI 也会犯错，我们要善于指导并给出合理的提示词，不能压力他们。有时打开代码注释几句，给出几百行自己能跑的代码比让他们发挥更好；自己先把家里的环境搭好，才能让 AI 工作更轻松。

01前三名

教程在演，对手在打

玩家还在读老陈那句「把骰子推到桌角」，对面 AI 已经掷完骰子糊了一脸伤害——_开本关引导() 是 fire-and-forget，谁也没等它。修的时候还不能每个小回合都等（那样「等你真做了某事」的步骤会把玩家自己的回合卡死），只能在 _执行大回合() 开头 await _等引导走开()。

02前三名

测试悄悄不跑了

验收场景的断言必须打 ✔ / ✘。有一次图省事打了 OK / XX，整套测试把那几个场景当成 TOOL 场景优雅跳过：不报错、不失败、直接不跑。看着「全绿」，其实什么也没测。

03前三名

名字被挤成一竖列

关于页重做后，截图里作者名字变成了一竖排：Y、a、n、g、C、h、e、n、2、2、3、5。同一个毛病在模组「班级管理」的空列表提示上又演了一遍。根因都是 autowrap 开着、横向只剩一个字宽。名字和标签一律 换行 = false，只有长文案才撑满加换行。

04少一个字符就全灭

一个逗号灭掉 52 个学生

数据/玉溪一中.json 末尾多了个逗号，报 Illegal trailing comma before end of object，整班名单一条都读不出来。删掉那个逗号，52 个人全回来了。

05少一个字符就全灭

BOM 两头都会咬人

PowerShell 5.1 的 Set-Content -Encoding UTF8 会偷偷写 BOM，Python 一读 .py 就 SyntaxError: invalid non-printable character U+FEFF；反过来，跑全部测试.ps1 必须有 BOM——没 BOM 时 PS 按 GBK 读中文，脚本静默不执行，一句话都不报。

06少一个字符就全灭

(Get-Content $f)[0] 只给了第一个字

拿 GitHub 凭据的时候，它返回的是字符串的第 0 个字符，不是第一行。我一度以为 token 只有 1 个字符长。

07看起来没坏，其实坏了

私有仓库的发行版，只有自己能下

链接填进网页看着完全正常，匿名 curl 却是 Recv failure: Connection reset——你登着 GitHub，当然能下。这就是后来必须开公开仓库 banjichouka-builds 的原因。

08看起来没坏，其实坏了

2.82 MB/s 的幻觉

测 ghfast.top 时 curl … 2>$null 把 TLS 证书错误一起吞了，量出一个漂亮的速度，其实一个字节都没下来。重测的规矩改成「落盘、核字节数、比 sha256」，才发现真正能用的是 gh-proxy.com（1.07 MB/s，字节一致）。

09看起来没坏，其实坏了

> 重定向让 git 看着干净

PowerShell 5.1 的 > 把二进制重定向写成 UTF-16，字节数直接翻倍。git status 一片干净，git cat-file 却对不上，我差点以为仓库坏了。

10看起来没坏，其实坏了

存档页的 visible 永远是 true

为了能测出滚动高度，代码让它恒真。「一页只亮一页」那个测试于是数出两页，连着误报两次。

11差一点酿成事故

差点把个人主页删了

数据/_scratch/_出网页版.py 第 ④ 步会清掉站点目录里除 .git、README.md 这些白名单以外的一切。仓库根变成个人主页、网页版搬进 play/ 之后，这个脚本就必须指到 play/——指到根，就是一次清空主页。

12差一点酿成事故

按钮的名字是接口

场景/关于游戏.tscn 底部那个按钮必须叫「退出」，因为 界面/设置界面.gd 和 界面/骰子对决/骰子对决主界面.gd 都用 get_node_or_null("退出") 去接自己的关闭逻辑。想改个更好听的名字，就静默失灵。

13差一点酿成事故

灰屏只画一个 Esc

早期录屏第一版整屏是灰的，右下角只有一个 Esc：Control 还没算好布局就 add_child 了。

14一行代码

一个直引号就 Parse Error

字符串里写了直引号，报 Parse Error: Expected closing ")"，所以工程里的引号一律用「」。多行 lambda 塞进调用参数、把协程存进变量再 await，报的也是同一个错。

最低设备建议

  • Windows：Windows 10 / 11 64 位，内存 4 GB 以上， 显卡支持 DirectX 12 或 Vulkan（近几年的核显基本都能跑）。 下载包 355 MB，解压后再留 1 GB 空间。
  • Linux：x86_64 桌面版，驱动支持 Vulkan 就行； 解压后记得先给可执行文件加执行权限。
  • Android：只导了 64 位 ARM（arm64-v8a），老一点的 32 位手机装不上； 包 349 MB，装之前留 1 GB 空间。
  • 网页版：Chrome / Edge 这类支持 WebAssembly 的现代浏览器； 第一次打开要下约 80 MB 游戏包，之后走缓存。

iOS 和 32 位 Windows 没有安装包

  • iPhone / iPad：Godot 导出 iOS 要 Xcode 签名再上架商店， 没这个条件，所以一直没做。用手机浏览器打开 网页版 就能玩；在 Safari 里点「分享 → 添加到主屏幕」，之后从桌面图标进，跟 App 差不多。
  • 32 位 Windows：只导了 64 位，系统要求 Windows 10/11 64 位、 显卡能跑 DirectX 12 / Vulkan。老机器和 32 位系统直接走网页版。
  • macOS：也没单独导出，同样用网页版。
网页版说明：第一次打开需要下载约 80 MB 的游戏包 （页面上有中文进度条），之后浏览器会缓存，再开就快很多。 网页版的存档存在浏览器本地，换浏览器或清缓存会丢，重要进度建议用桌面版。
